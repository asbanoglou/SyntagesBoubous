# SyntagesBoubous

A Windows app that sims a World of Warcraft: Forever character and finds gear upgrades, on your own computer.

## Getting it

Download `SyntagesBoubous.zip` from the latest release on the Releases page, unzip it and start `SyntagesBoubous.exe`.
Windows asks once whether to run it, since the app is not signed with a paid certificate: choose More info, then
Run anyway. From then on the app updates itself when a new version is out.
